# Tect by AK (Pro) 🏗️📐

**Tect by AK (Pro)** is a lightweight, mobile-first web application designed for architects, site managers, and spatial designers. It seamlessly converts 2D satellite map boundaries into real-world scaled 3D architectural massings, offers interactive sun path analysis, pre-loaded site assets, and exports CAD-ready DXF vector files directly from mobile or desktop browsers.

---

## ✨ Features

- **2D Satellite GIS Tracing:** High-resolution satellite imagery (via Esri) to outline land plots and building footprints.
- **Real-World Metrics:** Live site area ($m^2$) and perimeter ($m$) calculations using **Turf.js**.
- **Instant 3D Extrusion:** Automatic 3D building and site mesh generation using **Three.js**.
- **Real Sun Path Engine:** Dynamic solar angle and shadow simulation powered by **SunCalc.js** based on date, time, and GPS coordinates.
- **Pre-Loaded Architectural Assets:** Trees, vehicles (sedans, school buses), street lighting, and structural components.
- **Mobile First-Person Walkthrough:** Touch-optimized dual-stick controls for ground-level spatial navigation on smartphones.
- **CAD Export:** Direct vector export to layered **DXF** format compatible with AutoCAD, SketchUp, and mobile CAD viewers (e.g., DWG FastView).
